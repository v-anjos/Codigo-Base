# 🚀 Código Base

**Grupo de Estudos de Algoritmos**
IFTM – Campus Patrocínio

O **Código Base** é um projeto de ensino voltado ao desenvolvimento do **raciocínio lógico** e da **construção de algoritmos**, por meio de encontros presenciais, atividades remotas e desafios práticos de programação.

O objetivo do projeto é ajudar estudantes a compreender **conceitos fundamentais de algoritmos**, praticar resolução de problemas e desenvolver habilidades importantes para a programação.

---

# 📚 Conteúdo do Repositório
